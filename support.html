Frequently asked questions

Which tuning is included?
Standard four-string tuning: string 1 A2, string 2 D3, string 3 E3, string 4 A3. A4 defaults to 440 Hz and can be set from 415 to 466 Hz.

Why is there no sound?
Check the device volume and silent mode, then tap the reference tone again.

Does the app upload my audio?
No. Pitch is measured on this device. Nothing is recorded or uploaded.

Is there a subscription?
No. The one-time App Store purchase includes every feature. There is no separate subscription and no automatic renewal. Re-download with the same Apple ID.

中文帮助

包含哪种定弦？
标准四弦：第 1 弦 A2，第 2 弦 D3，第 3 弦 E3，第 4 弦 A3。A4 默认 440 Hz，可在 415 到 466 Hz 之间调整。

为什么没有声音？
请检查设备音量和静音模式，然后再次点击参考音。

会上传我的声音吗？
不会。音高只在本机测量，不会录制或上传。

有订阅吗？
没有。一次性购买包含全部功能，没有单独的订阅，也不会自动续费。可用同一 Apple ID 重新下载。
